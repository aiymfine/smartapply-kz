Built for the hiring funnel

Everything needed to reduce friction between "upload resume" and "submit application"

Resume parsing

PDF and DOCX ingestion via AI. Extracts personal info, work history, education, skills, projects, and languages into structured JSON.

Form autofill

Drop-in script detects form fields on job sites and fills them with parsed resume data. Handles Vue, React, and masked inputs.

Resume scoring

Quantitative 0–100 score across six categories: content, formatting, skills, experience, education, and keywords.

Cover letter generation

Context-aware cover letters based on the job description and candidate's actual experience. Russian, English, and Kazakh.

Job match analysis

Compare resume data against a job description. Returns match percentage, matched skills, and gaps.

Privacy-first

No accounts, no tracking. Resumes are processed and discarded. All candidate data stays in the browser by default.

How it works

Three steps from raw resume to completed application

STEP 01

Upload resume

Candidate uploads a PDF or DOCX. The API extracts structured data — personal info, experience, education, skills — in under two seconds.

STEP 02

Detect fields

The client-side script scans the job application form and maps detected inputs to resume fields. Works with Vue/Nuxt, React, and vanilla HTML.

STEP 03

Autofill

One click fills all matched fields. Properly triggers framework change events so SPA state stays in sync. Candidate reviews and submits.

API reference

RESTful endpoints. Send a resume, get structured data back.

# Parse resume from upload (multipart/form-data) POST /api/parse/upload → { "personal": { "fullName": "...", "email": "..." }, "skills": [...], "experience": [...] } # Score resume (0-100) POST /api/score → { "score": 78, "grade": "B+", "categories": {...}, "suggestions": [...] } # Generate cover letter POST /api/cover-letter → { "coverLetter": "Dear Hiring Manager..." } # Job match analysis POST /api/match → { "matchPercentage": 85, "matchedSkills": [...], "missingSkills": [...] } # Supported sites GET /api/sites → [{ "id": "kaspi-kz", "name": "Kaspi.kz", "fields": 13 }]
